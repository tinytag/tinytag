# Security Policy

## Supported Versions

tinytag follows a `A.B.C` versioning scheme. We only support the latest
released `A.B.x` series.

## Reporting a Vulnerability

Please report a vulnerability under the Security tab in the GitHub repository.
Since tinytag is a volunteer-driven project, your report will be reviewed and
addressed when the maintainers have time.
